# Ascendia: Core

A library our mods are built on. By itself it adds nothing to the game. It holds the code those mods share.

Part of the **Ascendia** mod family.

## For players

Most mods that use it carry it inside their own file. Download it yourself only when a mod lists it as required.

## Building

`./gradlew modJar` builds one jar for NeoForge and Fabric into `build/libs`.
