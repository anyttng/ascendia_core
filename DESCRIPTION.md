# Ascendia: Core

**A library our mods are built on. By itself it adds nothing to the game.** Ascendia: Core holds the code those mods share.

Most mods that use it carry it inside their own file, so there is nothing to install. Download it yourself only when a mod lists it as required.

## Compatibility

NeoForge and Fabric.

## Bug reports

Found something broken? Report it on the [issue tracker](https://github.com/anyttng/ascendia_core/issues).
